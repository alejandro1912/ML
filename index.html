Introducción al Machine Learning

Lo esencial para empezar: qué es, dónde se ubica dentro de la inteligencia artificial, cómo aprende una máquina a partir de datos, qué modelos existen y cómo se ve uno en Python. Cada concepto tiene una figura que puedes tocar.

1 · Dónde se ubica

El machine learning es una parte de la IA

La inteligencia artificial es el campo completo. El machine learning es la parte que aprende de datos; el deep learning es un tipo de machine learning, y la IA generativa es un uso del deep learning. Toca cada anillo.

2 · La idea central

En vez de escribir las reglas, la máquina las aprende de ejemplos

Programación tradicional

Datos
+
Reglas escritas por una persona
→
Respuestas

Ejemplo: "si el correo contiene la palabra gratis, márcalo como spam". Funciona hasta que los spammers cambian de palabra.

Machine learning

Datos
+
Respuestas conocidas
→
Reglas (el modelo)

Ejemplo: le das miles de correos ya marcados como spam o no spam, y el algoritmo descubre los patrones. Si cambian los correos, se vuelve a entrenar.

Definición de trabajo: el machine learning (aprendizaje automático) es el conjunto de técnicas que permiten a un computador mejorar en una tarea a partir de la experiencia, es decir, de datos, sin que cada regla se programe de forma explícita. El resultado del entrenamiento se llama modelo: una función que recibe datos nuevos y entrega una predicción.

3 · Cómo se hace

Un proyecto de ML sigue siempre el mismo recorrido

El algoritmo es solo una estación. La mayor parte del trabajo está en entender el problema y preparar los datos.

  1. 1
    Definir el problema¿Qué quiero predecir y para qué decisión?
  2. 2
    Reunir datosRegistros, sensores, encuestas, bases de datos.
  3. 3
    PrepararLimpiar, completar faltantes, transformar variables.
  4. 4
    EntrenarEl algoritmo ajusta el modelo con los datos de entrenamiento.
  5. 5
    EvaluarMedir el error con datos que el modelo nunca vio.
  6. 6
    Usar y vigilarPoner en producción y reentrenar si los datos cambian.

5 · Las tres formas de aprender

Supervisado, no supervisado y por refuerzo

La diferencia está en qué información recibe el algoritmo mientras aprende.

Aprende con un profesor

Cada ejemplo viene con su respuesta correcta (la etiqueta). El modelo aprende la relación entre las características y la etiqueta, y luego predice la etiqueta de ejemplos nuevos.

Regresión la etiqueta es un número: precio, temperatura, demanda.

Clasificación la etiqueta es una categoría: spam o no, enfermo o sano, especie.

En la figura, cada punto es un estudiante (horas de estudio y asistencia) con su resultado conocido. La línea es lo que el modelo aprendió; el punto con "?" es un estudiante nuevo.

Encuentra estructura sin respuestas

Los datos no tienen etiqueta. El algoritmo busca grupos, patrones o datos raros por sí solo.

Aquí, k-means agrupa puntos: elige k centros, asigna cada punto al centro más cercano y mueve cada centro al promedio de su grupo. Repite hasta que nada cambia.

Aprende por prueba y error

Un agente actúa en un entorno y recibe recompensas o castigos. Nadie le dice la acción correcta: aprende qué acciones convienen a largo plazo.

El robot debe llegar a la meta (+10) sin caer en los pozos (−10); cada paso cuesta −1. Usa Q-learning: las flechas muestran lo que aprendió en cada casilla.

7 · Predecir una categoría

Clasificación: dibujar una frontera entre clases

Un clasificador divide el espacio en zonas, una por clase. Este usa k vecinos más cercanos (k-NN): cada punto nuevo toma la clase que tienen la mayoría de sus k vecinos. Agrega estudiantes y cambia k.

Al hacer clic agregas:
—exactitud en entrenamiento
—ejemplos

Con k = 1 la frontera rodea cada punto y acierta el 100 % en entrenamiento, pero memoriza el ruido: eso es sobreajuste. Con k más grande la frontera se suaviza.

Clasificación binaria

Dos clases: fraude o no, falla o no, aprueba o reprueba. Modelos típicos: regresión logística, árboles, boosting.

Clasificación multiclase

Tres o más clases: especie de una flor, dígito escrito a mano, tipo de ataque en una red.

8 · Muchos modelos simples, uno fuerte

Boosting: cada árbol corrige los errores del anterior

Un árbol muy pequeño (un "tocón", con una sola pregunta) es un modelo débil. El gradient boosting los suma en secuencia: cada nuevo árbol se entrena con los residuos que dejaron los anteriores. Mueve el control.

—error entrenamiento (ECM)
—error prueba (ECM)

Puntos llenos: entrenamiento. Puntos huecos: prueba. Tasa de aprendizaje 0,5. Abajo, el error de prueba deja de bajar en algún momento: agregar más árboles ya no ayuda y puede empezar a sobreajustar.

Bagging (ej. Random Forest)

Entrena muchos árboles en paralelo, cada uno con una muestra distinta de los datos, y promedia o vota. Reduce la variabilidad. Robusto y fácil de usar.

Boosting (ej. XGBoost, LightGBM)

Entrena árboles en secuencia, cada uno enfocado en lo que el conjunto aún hace mal. Suele lograr la mejor precisión en datos tabulares, pero hay que cuidar el sobreajuste.

10 · ¿Funciona?

Evaluar: medir con datos que el modelo no vio

Métricas de regresión

MétricaQué mide
MAEError absoluto medio, en las mismas unidades que la etiqueta.
RMSERaíz del error cuadrático medio; castiga más los errores grandes.
R²Proporción de la variación explicada; 1 es perfecto, 0 es igual a predecir el promedio.

Métricas de clasificación

MétricaQué mide
ExactitudPorcentaje de aciertos. Engaña si una clase es muy rara.
PrecisiónDe lo que el modelo marcó como positivo, cuánto lo era.
RecallDe los positivos reales, cuántos encontró (sensibilidad).
F1Equilibrio entre precisión y recall.
Matriz de confusiónTabla de aciertos y errores por clase.

Ejemplo: si solo el 1 % de las transacciones es fraude, un modelo que siempre dice "no es fraude" tiene 99 % de exactitud y 0 % de recall. Por eso la métrica se elige según el problema.

    13 · Para no perderse
    
    
    Glosario y próximos pasos
    
    
    
      
    Dataset
    Conjunto de datos: filas (ejemplos) y columnas (variables).
    
      
    Característica (feature)
    Variable de entrada que usa el modelo.
    
      
    Etiqueta (target)
    Lo que se quiere predecir.
    
      
    Entrenamiento
    Proceso en que el algoritmo ajusta el modelo a los datos.
    
      
    Inferencia
    Usar el modelo ya entrenado para predecir con datos nuevos.
    
      
    Hiperparámetro
    Ajuste que se elige antes de entrenar: k en k-NN, profundidad de un árbol, número de árboles.
    
      
    Sobreajuste
    El modelo memoriza los datos de entrenamiento y generaliza mal.
    
      
    Validación cruzada
    Repetir la división entrenamiento/prueba varias veces para una evaluación más estable.
    
      
    Ingeniería de características
    Crear o transformar variables para que el modelo aprenda mejor.
    
      
    Sesgo en los datos
    Si los datos no representan bien la realidad, el modelo repetirá ese error.
